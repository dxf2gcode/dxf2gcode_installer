Only for Debian (e.g. Ubuntu, Mint) & Arch (e.g. CachyOS) based OSes!

Enter in the console:

**cd ~/Downloads**<br>
**wget https://raw.github.com/dxf2gcode/dxf2gcode_installer/main/install.sh**<br>
**chmod a+x install.sh**<br>
**./install.sh**<br>


Then follow the instructions. The script will install all necessary packages and dxf2gcode automatically.


Python 3.9 or higher is required. This is checked by the script.


The script is tested on:<br>

**Debian** 13 with MATE<br>
**Kubuntu** 26.04 (KDE)<br>
**Linux Mint**: 22.3 MATE<br>

**CachyOS**<br>


The installation is ONLY complete when the script "**dxf2gcode was successfully installed.**" spends in light-cyan!<br>


Developer versions on<br>
https://github.com/dxf2gcode/dxf2gcode<br>

The script can download and install this automatically.<br>
